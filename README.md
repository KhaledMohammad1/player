# Player — Android edition of Shaghal

This repository is a separate Android-focused port of [Shaghal](https://github.com/UserJoo9/Shaghal), a Flutter audio and video player.

The original Dart application source is retained, with the Android project generated by Flutter during setup/build. The upstream project is primarily configured for iOS; this repository adds Android dependency configuration and an automated APK workflow.

## Features carried over

- Audio and video playback through `media_kit` / libmpv.
- Folder-based media library, nested folders, import files and folders.
- Music, videos and favorites views.
- Arabic and English interface.
- Background audio and Android media notification / lock-screen controls.
- Embedded audio artwork and video thumbnails.
- Dark interface and playback controls.

## Build APKs on GitHub

1. Open the **Actions** tab.
2. Select **Build Android APK**.
3. Choose **Run workflow** on the `main` branch.
4. When the run completes, download the `Player-Android-APKs` artifact.

The workflow builds split APKs for the available Android ABIs. For older 32-bit Android installations, use the `armeabi-v7a` APK. For 64-bit Android, use `arm64-v8a`.

## Build locally

Requirements: Flutter stable, Android SDK, Java 17.

```bash
chmod +x setup_android.sh
./setup_android.sh
```

The script creates the Flutter Android project in `app/`, installs the Android media dependencies and builds release APKs.

## Device compatibility note

The Redmi A3 family has shipped with 32-bit Android software on some configurations even though its processor is 64-bit. Therefore, the build is configured to produce an `armeabi-v7a` APK as well as an `arm64-v8a` APK. Actual installation and playback still need to be verified on the target phone.
