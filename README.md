# Player — Android build

Android port of [Shaghal](https://github.com/UserJoo9/Shaghal), maintained as a separate project. The Android setup and CI build are being prepared.

## Device compatibility

The initial build targets Android ARM 32-bit (`armeabi-v7a`) and ARM64 (`arm64-v8a`) where supported by the native media dependencies.
